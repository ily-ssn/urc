# URC photograph brief · updated 28 October 2026

The pages reuse URC's organiser photographs until the owner supplies replacements. Baztan images are design references and are not published as URC event photos.

The revised layout needs **19 image files: 8 horizontal and 11 vertical** if every placement gets its own image. This is **18 photographs and one official event poster**. The poster is reused for the RESET card and its detail cover. The homepage recap photo and portrait were removed at the owner's request.

Portraits should ideally be 1500px on the short edge. Send originals without app overlays. Keep subjects away from the extreme edges so mobile crops work. File names matching this list make placement straightforward.

Gallery albums remain separate: send photographs grouped by run, with photographer credits and any download restrictions. Existing organiser media stays in the current community album until replaced or supplemented.

## Brand files

Use the owner's supplied circular R/URC artwork and COMMUNITY wordmark. The old Eventbrite emblem is not used. The inline images have no downloadable file reference in this workspace; the actual PNG/SVG originals in a ZIP are still needed. Do not approximate the marks with a font or regenerate them. The logo entrance remains inactive until the approved downloadable artwork is present.
